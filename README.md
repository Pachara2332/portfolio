# Pachara's Portfolio

Personal developer portfolio showcasing selected web, AI, and mobile projects with detailed case studies, live demos, source links, and product galleries.

## Live Site

[View the portfolio on Vercel](https://portfolio-three-delta-scjek3jdc2.vercel.app/)

## Highlights

- Responsive project showcase with featured work and category filters
- Dedicated project detail pages with challenges, outcomes, and technology stacks
- Screenshot galleries for product flows and dashboard screens
- Nested case studies for projects with multiple applications, such as the LINE OA Membership & CRM MVP
- Contact API endpoint and Vercel Analytics integration

## Featured Projects

- **Enterprise Knowledge Platform** - Multi-tenant AI SaaS with federated OAuth, ChromaDB RAG search, and provider failover
- **Eleven Lineup** - Football community platform with lineup building, fixtures, profiles, and mini games
- **Movie Operations Dashboard** - Authenticated movie catalog management tool with role-aware workflows
- **LINE OA Membership & CRM MVP** - LIFF member acquisition flow and multi-tenant CRM dashboard
- **Noir Cinema Booking** - React Native cinema discovery and seat booking experience

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Vercel Analytics

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

```bash
npm run dev
npm run lint
npm run build
npm run start
```

## Project Structure

```text
app/                  App Router pages and API routes
components/           Reusable UI components
data/projects.ts      Portfolio project content and gallery metadata
public/assets/        Project covers and screenshots
types/                Shared TypeScript types
```
